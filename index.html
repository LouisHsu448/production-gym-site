🌟 什麼是 Production 體育館？

Production 體育館（プロダクション体育館） 是源自日本的知名獸圈偶像與演藝經紀社團。結合了 K-Pop 風格的邊唱邊跳、精緻的獸裝工藝，以及幕後製作人「あお丸」的用心企劃，每一個成員都在這裡找到了屬於自己的發光舞台，展現出充滿熱血與夢想的偶像大家庭氛圍。

🦊 體育館最出名的靈魂王牌：Rion（リオン）

  • 超可愛的狐狼設定：我們家的 Rion 是一隻年僅 13歲、擁有天藍色外型、帥氣又迷人的狐狼！
  • 招牌「炸蝦呆毛」：只要看過一眼就絕對忘不了！頭頂上那根高後豎起、橘色捲曲的呆毛，看起來簡直就像一隻剛炸好的美味炸蝦，萌度直接突破天際！
  • 無可取代的 C 位：身為體育館人氣最高、最出名的頂樑柱，在 K-Pop 舞蹈翻跳中總是展現出頂尖實力與耀眼的 C 位光芒，狙擊了無數粉絲的心。

🐺 傳奇的 PRIME（元初組）小組成員與故事

PRIME 是體育館最初的基石，象徵著素數的無敵三人元初組合，代表曲為充滿羈絆的神曲 《友誼讚歌》：

  • Nox（諾克斯）：設定為 17歲的藍狼，臉部有著非常顯眼的黃色 X 標記，擔任 PRIME 小組的 Leader（隊長），總帶著溫柔又可靠的領袖風範。
  • Rion（リオン）：站在中央、用無敵舞技與炸蝦呆毛擄獲所有人心的 C 位。
  • Rotta（羅塔）：設定為 11歲的灰色兔子。原本也是元初組不可或缺的重要成員，但因身體因素已於 2025年4月畢業（退出）。雖然不捨，但大家給予最深的祝福；隨著 Rotta 畢業，PRIME 也隨之更改為兩人小組繼續奔跑！
